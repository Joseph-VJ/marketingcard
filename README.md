# Marketing Card - Digital Calling Card

A responsive, modern editorial digital calling card. Designed for quick contact exchange, WhatsApp messaging, one-tap calling, directions, and instant `.vcf` phonebook export.

## ✨ Features
- **Demo & Testing Ready**: Pre-configured with clean test placeholders (`John Doe`, `+91 98765 43210`, `demo@example.com`).
- **Dynamic Testing via Query Parameters**: Easily test different profiles by adding URL parameters:
  - Example: `https://joseph-vj.github.io/marketingcard/?name=Vijay+Joseph&phone=9876543210&email=vijay@example.com&company=Acme+Realty`
- **One-Tap Actions**:
  - Direct Phone Call (`tel:`)
  - Direct WhatsApp Messaging (`wa.me`)
  - Direct Email (`mailto:`)
  - Google Maps Directions
- **Download Contact Card (`.vcf`)**: Instant export to smartphone address books.
- **Dynamic QR Code**: Generates a shareable QR code for the current URL.
- **Zero Framework / Zero Dependencies**: Ultra-fast pure HTML/CSS/JavaScript.
