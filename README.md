# Marketing Card - Digital Calling Card

A responsive, modern editorial digital calling card for Arun Kumar (Property and Investment Consultant in Chennai).

## ✨ Features
- **Responsive Layout**: Designed for seamless browsing across mobile and desktop.
- **Direct Actions**: Quick-dial call, WhatsApp direct messaging, email, and Google Maps direction links.
- **Contact Card Download (.vcf)**: One-click export to download and save contact details directly to mobile address book.
- **QR Code & Share**: Shareable link copying and QR code generator.
- **Standalone**: Pure HTML/CSS/JavaScript with zero external framework dependencies.

## 🚀 Live Preview
Open `index.html` or `arun-kumar-digital-card.html` in any modern web browser.
